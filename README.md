# EricCyclesABit

A personal Streamlit dashboard for tracking cycling goals against your real ride history — pulled from a Strava export and a TrainerRoad export.

## Setup

```bash
pip install -r requirements.txt
streamlit run app.py
```

## Getting your data

**Strava** (source for distance, elevation, and consistency/volume):
1. Go to Strava → Settings → My Account → "Download or Delete Your Account" → request a **Bulk Export**.
2. Strava emails you a zip file. Upload that zip directly on the Upload Data page, or unzip it and upload just `activities.csv`.

**TrainerRoad** (source for FTP / power progression):
1. From trainerroad.com, export your workout history / career CSV.
2. Upload it on the Upload Data page. Column names vary across TrainerRoad's export versions, so the parser matches on keywords (date, FTP, power, TSS, etc.) rather than exact headers — if a field doesn't populate, check that your export includes it.

Uploaded data is parsed and cached locally under `data/` (git-ignored) so you don't need to re-upload every time you restart the app.

## Goal types

Configure targets for each on the **Goals** page:

- **FTP / power** — target FTP by a target date, tracked from TrainerRoad's recorded FTP values over time.
- **Distance** — target annual mileage, with a projection based on your current year-to-date pace.
- **Elevation / climbing** — target annual elevation gain, same pace projection.
- **Consistency / volume** — target rides per week, tracked as a trailing 4-week average.

## Design notes

Strava is treated as the source of truth for ride volume, distance, and elevation (it captures both outdoor and synced indoor rides). TrainerRoad is used specifically for FTP history and structured-workout power data, since Strava's export doesn't reliably carry FTP over time. The two are not merged/deduplicated — they answer different questions.

## Sample data

`sample_data/` has synthetic activity/workout CSVs (generated by `scripts/generate_sample_data.py`) so you can try the app before uploading real exports — click "Load sample data" on the Upload Data page.
